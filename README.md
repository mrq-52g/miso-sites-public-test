# 나인트리 홈페이지 재구축 종료 관리 대시보드

나인트리 홈페이지 재구축 프로젝트의 종료 일정과 요청 처리 현황을 관리하기 위한 비공개 인터랙티브 대시보드입니다.

- **실행 링크(Artifact, 비공개):** https://claude.ai/code/artifact/ebeff210-be4d-458b-9d9d-738608d6adba
- **소스:** [`naintree-dashboard.html`](./naintree-dashboard.html)

## 반영된 일정

| 일자 | 항목 |
| --- | --- |
| 2026-08-27 | 오픈 완료 |
| 2026-08-28 | 화면 수정 요청 접수 종료 |
| 2026-09-03 | 기능 수정 요청 접수 종료 · 주간보고 시 최종 취합 결과 공유 |
| 2026-09-04 | 산출물 전달 |
| 2026-09-09 | 최종 배포 |
| 2026-09-10 | 종료 보고 |
| ~2026-12-31 | 연말까지 긴급 수정 대응 (담당: 김현석 차장) |

## 기능

- 오픈부터 종료 보고까지의 일정과 연말 긴급 수정 대응 구간을 보여주는 타임라인 (오늘 날짜 기준 진행 상태 자동 표시)
- 최종 배포 · 종료 보고까지 남은 일수(D-day) 자동 계산
- 요청 유형(화면 수정 / 기능 수정 / 산출물 / 최종 배포 / 종료 보고 / 긴급 수정)별 상태 · 담당자 · 마감일 · 다음 액션을 입력·수정·삭제
- 유형 / 상태 / 담당자 기준 필터링
- Claude Artifact의 `db` 기능을 통해 조직 내 열람자가 실시간으로 상태를 함께 갱신 (조직 외부에는 비공개)

## 배포 방식

이 대시보드는 Claude Artifact로 게시되어 조직 내부 전용 링크로만 접근 가능합니다. 별도 시스템 변경이나 외부 공개 없이 위 링크로 바로 사용할 수 있습니다.
